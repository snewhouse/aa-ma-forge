## Pattern
Plugin framework: the product is markdown (commands, skills, agents, rules) plus bash hooks, deployed into `~/.claude/` by symlink (`scripts/install.sh:2`). Python CLIs under `src/aa_ma/` back the markdown where parsing must be exact. Inside Python the design is layered, and import-linter enforces the layers (`.importlinter:36`).

## Core components
- **aa-ma-gate** answers the seven milestone-gate questions over `grammar` + `enforce` + `plan_parsers`, and refuses rather than guesses (`src/aa_ma/gate.py:1`).
- **render** is a leaf: nothing in `aa_ma` may import it (`.importlinter:57`).
- **aa_ma never imports codemem**. It reads codemem's SQLite file with stdlib `sqlite3`, so the contract between them is the on-disk schema (`src/aa_ma/render/graph.py:3`, `.importlinter:21`).
- **codemem MCP server** registers 13 tool slots on FastMCP (`claude-code/codemem/mcp/server.py:1`).

## Request / job lifecycle
1. **Milestone gate:** `/execute-aa-ma-milestone` bash fence → `aa_ma_gate` launcher in `claude-code/hooks/lib/aa-ma-parse.sh` (`claude-code/commands/execute-aa-ma-milestone.md:549`) → `main` (`src/aa_ma/gate.py:449`) → `answer` (`src/aa_ma/gate.py:335`) → exit 0/1/2/3/4 (`src/aa_ma/gate.py:24`).
2. **Tracker:** `aa-ma-tui` → `main` (`src/aa_ma/tui/__main__.py:121`) → `discover_tasks` (`src/aa_ma/tui/parser.py:271`) → `AAMAApp` (`src/aa_ma/tui/__main__.py:131`).
3. **Index:** `codemem build` → `main` (`packages/codemem-mcp/src/codemem/cli.py:447`) → writes `.codemem/index.db` (`packages/codemem-mcp/src/codemem/cli.py:33`).

## Data model
- AA-MA state lives in markdown files under `.claude/dev/active/<task>/`, and the typed view of them is the Pydantic Task/Milestone/Step model (`pyproject.toml:23`). There is no ORM and there are no migrations.
- codemem state is a SQLite file at `.codemem/index.db`, guarded by a writer lock at `.codemem/db.lock` (`packages/codemem-mcp/src/codemem/cli.py:111`).

## Strengths / concerns
- Strengths: one grammar SSoT replaced hand-written awk (`claude-code/commands/execute-aa-ma-milestone.md:546`). Layer contracts run in CI (`.github/workflows/security.yml:147`).
- Concerns: the leaf contract lists every `aa_ma` module by hand, so a new module needs a manual edit to `.importlinter` (`.importlinter:60`). Symlinked deploy means an edit in the repo is live immediately for installed users (`scripts/install.sh:195`).
