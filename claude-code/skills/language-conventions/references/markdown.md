# Markdown card (pointer)

Markdown has its standard in its topic skills; this card only routes.

- `Skill(writing-for-agents)` — skills, `AGENTS.md`, `CLAUDE.md` and any document an agent will read.
- Hardcoded counts go stale: when a change adds or removes an asset, update every doc that counts it in the same commit.
- Historical docs (`docs/plans/`) are frozen; do not update them retroactively.
